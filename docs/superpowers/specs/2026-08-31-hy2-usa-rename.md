# Переименование резервного выхода HY2-USA

## Цель

Заменить действующий резервный Hysteria2-профиль на предоставленный пользователем US-профиль и сделать его каноническим именем HY2-USA во всей рабочей системе.

## Требования

- Fallback остаётся WG-IMP → HY2-USA; WG-IMP не отключается, а WireGuard-клиенты и их ключи не изменяются.
- Конфигурация Mihomo меняется точечно: Hysteria2-блок, fallback-ссылка и provider для правил, без пересоздания остальных правил, GeoData или DNS.
- Port-hopping используется через официальное поле Mihomo ports.
- Dashboard API, backend, frontend, policy-файлы и health/probe collectors используют HY2-USA.
- Существующие SQLite policy, probe и route rows с прежним именем мигрируются один раз до отдачи API, исторические audit-тексты не раскрывают секреты и не переписываются.
- Файл managed-hy2-nl.txt переносится в managed-hy2-usa.txt без потери правил и с прежними правами.
- Создаются закрытые backup конфигурации, секрета, policy-файла и SQLite до изменения; любая ошибка возвращает предыдущее состояние.
- Секреты не попадают в Git, журналы, API или аргументы командной строки. Единственное интерактивное значение, которое необходимо для применения на NAS, — пароль sudo.

## Проверка

- Mihomo валидирует конфигурацию до и после изменения.
- Аутентифицированный hot-reload проходит успешно.
- Отдельный delay-test HY2-USA успешен, не меняя fallback-выбор.
- После перезапуска dashboard новые значения API/API UI — HY2-USA, существующая policy перенесена и старых active-reference HY2-NL нет.
- При отрицательном тесте конфигурация, policy-файл и SQLite восстанавливаются из backup.
