# Anti-DPI: независимое обновление DNS

Согласовано владельцем 08.10.2026: заменить только источник DNS пяти контрольных
имён нового изолированного Anti-DPI. DNS клиентов, основной Mihomo, fallback,
профили и правила не меняются. Работа в текущей ветке, без агентов и повторного
согласования дизайна. Авторская проверка не является независимым review.

## Контракт

- Фиксированные HTTPS JSON DNS API Cloudflare и Google, проверка сертификата и
  имени сервера. Bootstrap только через заданные публичные IP, без системного
  DNS, переменных proxy, redirect или входных URL пользователя.
- Только пять имён из закрытого каталога. Проверять вопрос, A/CNAME-цепочку,
  публичный IPv4, TTL и HTTP Age. Не доверять посторонним ответам, частным IP,
  FakeIP, усечённым ответам или DNS-ошибкам. JSON — документированный контракт
  этих двух провайдеров, не универсальный DNS-протокол.
- Отдельные абсолютные сроки и предварительное обновление каждого имени;
  второй провайдер при отказе, коротком TTL или смене выбранного IP. Сохранять
  прежний IP только если он присутствует в новом проверенном ответе либо его
  прежний TTL ещё не истёк. Не продлевать TTL при ошибке.
- Не более пяти параллельных задач, двух запросов на имя за цикл, 4 секунды на
  соединение и 6 секунд общего бюджета запроса, ответ до 32 KiB. Отдельный DNS
  цикл не блокируется Docker-проверками. При истечении срока — fail closed.
- Прежний формат dns.json, без новых портов/контейнеров/библиотек. Автосмена и
  подключение клиентов остаются выключенными до полноценной приёмки.

## Выполнение

1. RED → GREEN: строгий разбор, TTL с учётом времени запроса и Age, отказ одного
   провайдера, несвязанные CNAME/A, обновление только нужных имён, сохранение
   непросроченного кеша при ошибке, запрет продления/использования просроченного.
2. Проверить доступность API на NAS; затем заменить только новый worker после
   зашифрованной резервной копии и проверки восстановления. Новая идентичность
   кода аннулирует старые разрешения; образы и основной VPN неизменны.
3. Наблюдать DNS не менее десяти минут/нескольких TTL; HTTPS по четырём сервисам.
   Не выдавать это за проверку приложений, клиентского пути или автопереключения.
4. Отдельно диагностировать красные карточки VPN. Старые тайм-ауты контроллера
   не считать доказанным периодом отказа канала. Рабочий /delay не вызывать.

Документация API: [Cloudflare](https://developers.cloudflare.com/1.1.1.1/encryption/dns-over-https/make-api-requests/dns-json/),
[Google](https://developers.google.com/speed/public-dns/docs/doh/json).
