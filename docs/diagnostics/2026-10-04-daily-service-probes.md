## Что реализовано

- Три фиксированных route ID (`direct/primary/reserve`) и три отдельных скрытых singleton-select wrapper. Преобразование конфигурации идемпотентно, сохраняет всё вне своего блока; само не имеет внешних эффектов.
- 36 контрольных HTTPS-сайтов; проверка публичности DNS, структуры wrapper и свежего per-URL результата. Ни основной/резервный выход, ни health-группы не получают `/delay` от нового коллектора.
- Последовательный сбор раз в локальную дату после 04:30, 25-минутная граница, атомарный claim, частичные результаты, 30-дневная история с сохраняемым watermark. Открытие API/UI не запускает сетевые проверки.
- На плитках — три результата, задержка и дата; при раскрытии — URL, подпись выхода на момент замера и причина. Широким категориям/GeoIP не приписывается проверка всех доменов/сетей. Ошибка чтения замеров не блокирует редактирование правил.

## Проверки и ограничения

Использованы реальные SQLite-транзакции/потоки и mock HTTP-контроллер; это не эмуляция всего Mihomo и не live-тест VPN. Source-review относится к pinned Mihomo v1.19.28: [Selector](https://github.com/MetaCubeX/mihomo/blob/v1.19.28/adapter/outboundgroup/selector.go), [URLTest](https://github.com/MetaCubeX/mihomo/blob/v1.19.28/adapter/adapter.go), [controller](https://github.com/MetaCubeX/mihomo/blob/v1.19.28/hub/route/proxies.go). Установленный на NAS бинарный файл требует отдельной приёмки.

Обнаруженное при авторском ревью: `unified-delay` заставляет URLTest отправить второй HEAD. Добавлены четыре отрицательных теста (сначала 4 failed, затем 22/22 transport tests passed); теперь без подтверждённого `false` HEAD не выполняется. Глобальная конфигурация не меняется. Причина видна как `probe_mode_invalid`.

HEAD не доказывает вход/видео/UDP/работу приложения. DNS preflight не защищает от изменения ответа между разрешением и соединением; поэтому разрешён только встроенный каталог. HTTP 2xx/3xx может быть страницей CAPTCHA. При отказе API точный код или причина соединения не придумываются.

## Принятые решения

1. В API используются role-ID, не произвольные имена выходов: ошибочное решение потребует изменения контракта API, но не меняет маршруты.
2. Текущий checkout сохранён без автоматического коммита/публикации; авторское ревью вместо агента по указанию владельца. Цена — отсутствие независимой проверки.
3. `unified-delay=true` либо неподтверждённый режим → неизвестный результат без запроса; цена — отсутствие замеров до отдельного решения, вместо изменения рабочего VPN.

Слияние/публикация и live-приёмка в эту поставку не входят. Записи `.superpowers` оставлены локально до согласованного коммита, чтобы не потерять доказательства незакоммиченной работы.
